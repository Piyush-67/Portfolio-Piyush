# Portfolio-Piyush

A modern, interactive, and responsive personal portfolio website built with HTML to showcase professional identity, projects, team members, and testimonials — with simple visuals and content. This site also includes contact information for easy communication.

---

## 🚀 Project Description

This portfolio is designed to represent a **full-stack developer** leading a small team, highlighting:

- Professional profile and summary  
- Team member photos  
- Personal images and visuals  
- Skills and experience (via HTML content)  
- Contact information (including direct WhatsApp link option)

The website is built using plain **HTML** and static assets. :contentReference[oaicite:1]{index=1}

## 📌 How to View Locally

Since this is a static HTML website, you can run it easily:

1. **Clone the repository**
   ```bash
   git clone https://github.com/Piyush-67/Portfolio-Piyush.git
   ```
2. **Navigate to the folder**
   ```bash
   cd Portfolio-Piyush
   ```
3. **Open the main HTML file**
   - Double-click `piyush.html`  
   **OR**
   ```bash
   open piyush.html
   ```
   in your preferred browser.
